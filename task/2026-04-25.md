# 流式输出改造任务

**目标**: 将面试对话框的大模型输出改为流式输出，前端实时显示打字效果

**日期**: 2026-04-25

---

## 一、架构说明

### 1.1 当前架构（非流式）
```
用户发送回答 → 后端同步调用LLM → 等待完整响应 → 返回JSON → 前端渲染
```

### 1.2 目标架构（流式）
```
用户发送回答 → 后端流式调用LLM → SSE推送 → 前端逐字显示
```

### 1.3 技术选型
- **后端流式**: SSE (Server-Sent Events) + OkHttp 流式读取
- **前端**: EventSource 或 Fetch API + ReadableStream

```java
/**
 * 流式调用 LLM，返回 Flux<String> 用于 SSE
 */
public Flux<String> streamCallLlm(
        List<Map<String, String>> messages,
        AppSettings.ModelConfig modelConfig
) {
    String apiKey = modelConfig.getApiKey();
    String baseUrl = modelConfig.getBaseUrl();
    String model = modelConfig.getModel();

    if (apiKey == null || apiKey.isBlank()) {
        return Flux.error(new IllegalStateException("API Key 未配置"));
    }

    String url = baseUrl.endsWith("/") ? baseUrl + "/chat/completions" : baseUrl + "/chat/completions";
    String requestBody = buildStreamRequestBody(model, messages);

    return Flux.create(sink -> {
        try {
            executeStreamRequest(url, apiKey, requestBody, sink);
        } catch (Exception e) {
            sink.error(e);
        }
    });
}

private void executeStreamRequest(String url, String apiKey, String requestBody, FluxSink<String> sink) {
    Request request = new Request.Builder()
            .url(url)
            .addHeader("Authorization", "Bearer " + apiKey)
            .addHeader("Content-Type", "application/json")
            .post(RequestBody.create(requestBody, JSON))
            .build();

    HTTP_CLIENT.newCall(request).enqueue(new Callback() {
        @Override
        public void onFailure(Call call, IOException e) {
            sink.error(e);
        }

        @Override
        public void onResponse(Call call, Response response) throws IOException {
            try (BufferedReader reader = new BufferedReader(
                    new InputStreamReader(response.body().byteStream(), StandardCharsets.UTF_8))) {
                String line;
                while ((line = reader.readLine()) != null && !sink.isCancelled()) {
                    if (line.startsWith("data: ")) {
                        String data = line.substring(6);
                        if ("[DONE]".equals(data)) {
                            sink.complete();
                            return;
                        }
                        String content = extractStreamContent(data);
                        if (content != null && !content.isBlank()) {
                            sink.next(content);
                        }
                    }
                }
                sink.complete();
            }
        }
    });
}

private String buildStreamRequestBody(String model, List<Map<String, String>> messages) {
    StringBuilder sb = new StringBuilder();
    sb.append("{\"model\":\"").append(model).append("\",\"messages\":[");
    for (int i = 0; i < messages.size(); i++) {
        Map<String, String> msg = messages.get(i);
        sb.append("{\"role\":\"").append(escapeJson(msg.get("role")))
          .append("\",\"content\":\"").append(escapeJson(msg.get("content"))).append("\"}");
        if (i < messages.size() - 1) sb.append(",");
    }
    sb.append("],\"stream\":true}");
    return sb.toString();
}

private String extractStreamContent(String data) {
    try {
        JsonNode root = objectMapper.readTree(data);
        JsonNode choices = root.get("choices");
        if (choices == null || !choices.isArray() || choices.size() == 0) return null;
        JsonNode delta = choices.get(0).get("delta");
        if (delta == null) return null;
        JsonNode content = delta.get("content");
        if (content == null) return null;
        return content.asText();
    } catch (Exception e) {
        return null;
    }
}
```

```java
@GetMapping(value = "/conversation/{id}/stream-answer", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<String> streamAnswer(@PathVariable String id, @RequestParam String answer) {
    try {
        if (id == null || id.isBlank()) {
            return Flux.just("data: {\"error\":\"对话ID不能为空\"}\n\n");
        }
        if (answer == null || answer.isBlank()) {
            return Flux.just("data: {\"error\":\"回答内容不能为空\"}\n\n");
        }
        
        AppSettings settings = settingsService.getSettings();
        ModelConfig modelConfig = settings.getModelConfig();
        
        if (modelConfig == null || modelConfig.getApiKey() == null || modelConfig.getApiKey().isBlank()) {
            return Flux.just("data: {\"error\":\"请先配置大模型API\"}\n\n");
        }

        Conversation convo = conversationService.getConversation(id)
                .orElseThrow(() -> new IllegalArgumentException("对话不存在"));

        List<Message> messages = convo.getMessages();
        String currentQuestion = messages.stream()
                .filter(m -> Boolean.TRUE.equals(m.getIsQuestion()))
                .reduce((first, second) -> second)
                .map(Message::getContent)
                .orElse("");

        // 构建评分用的 messages（不包含流式输出）
        List<Map<String, String>> evalMessages = buildEvalMessages(messages, currentQuestion, answer);
        
        // 流式返回评估结果 + 下一题
        return conversationService.streamProcessAnswer(id, answer, evalMessages, modelConfig);
        
    } catch (IllegalArgumentException e) {
        return Flux.just("data: {\"error\":\"" + e.getMessage() + "\"}\n\n");
    } catch (Exception e) {
        log.error("流式处理失败: {}", e.getMessage(), e);
        return Flux.just("data: {\"error\":\"处理失败: " + e.getMessage() + "\"}\n\n");
    }
}
```

```java
/**
 * 流式处理回答：评分 → 判断结束 → 生成下一题
 */
public Flux<String> streamProcessAnswer(
        String convoId,
        String userAnswer,
        List<Map<String, String>> evalMessages,
        ModelConfig modelConfig
) {
    ReentrantLock lock = lockFor(convoId);
    if (!lock.tryLock()) {
        return Flux.just("data: {\"error\":\"系统繁忙，请稍后\"}\n\n");
    }

    try {
        Conversation convo = convoCache.get(convoId);
        if (convo == null) {
            return Flux.just("data: {\"error\":\"对话不存在\"}\n\n");
        }

        String now = LocalDateTime.now().format(DTF);

        // 1. 流式返回评分结果
        String candidateProfile = buildProfileSummary(
                convo.getCandidateProfile(),
                getSetting(convo, "position", "软件工程师"),
                getSetting(convo, "experience", "")
        );

        String skillQuestionsContext = getSkillQuestionsContext(convo);
        String evaluationPrompt = buildEvaluationPrompt(currentQuestion, userAnswer, candidateProfile, skillQuestionsContext);

        List<Map<String, String>> messages = new ArrayList<>();
        messages.add(Map.of("role", "system", "content", "你是一位专业的面试官评估专家"));
        messages.add(Map.of("role", "user", "content", evaluationPrompt));

        return Flux.concat(
                // 评分结果流（这里仍然一次性返回，因为评分内容较短）
                Flux.defer(() -> {
                    String evalResult = llmHelper.call("Evaluator 评分", messages, modelConfig, "{\"score\":5,\"feedback\":\"评估服务暂时不可用\"}");
                    return Flux.just("data: " + formatSseEvent("eval", evalResult) + "\n\n");
                }),
                // 下一题流式输出
                Flux.defer(() -> generateNextQuestionStream(convo, modelConfig))
        );
    } finally {
        lock.unlock();
    }
}

private Flux<String> generateNextQuestionStream(Conversation convo, ModelConfig modelConfig) {
    int nextIndex = convo.getCurrentQuestionIndex() + 1;
    String position = getSetting(convo, "position", "软件工程师");
    String experience = getSetting(convo, "experience", "");
    String profileSummary = buildProfileSummary(convo.getCandidateProfile(), position, experience);

    List<Map<String, String>> promptMessages = new ArrayList<>();
    promptMessages.add(Map.of("role", "system", "content", buildInterviewerSystemPrompt(position, experience)));
    promptMessages.add(Map.of("role", "user", "content", "请生成第" + nextIndex + "道面试问题"));

    return llmService.streamCallLlm(promptMessages, modelConfig)
            .map(content -> "data: " + formatSseEvent("question", content) + "\n\n")
            .startWith(Flux.just("data: " + formatSseEvent("status", "streaming") + "\n\n"))
            .onErrorResume(e -> Flux.just("data: " + formatSseEvent("error", e.getMessage()) + "\n\n"))
            .concatWith(Flux.just("data: " + formatSseEvent("done", "true") + "\n\n"));
}

private String formatSseEvent(String event, String data) {
    return "{\"event\":\"" + event + "\",\"data\":" + escapeJson(data) + "}";
}
```

#### 3.1.2 修改 sendAnswer 函数为流式版本

找到 `async function sendAnswer()` 函数，替换为:

```javascript
async function sendAnswer() {
    var input = document.getElementById('answer-input');
    var answer = input.value.trim();
    var sendBtn = document.getElementById('send-btn');
    
    if (!answer) {
        alert('请输入回答');
        return;
    }
    if (!isInterviewActive) return;
    
    input.disabled = true;
    sendBtn.disabled = true;
    sendBtn.textContent = '⏳ 生成中...';
    
    // 添加用户消息
    var userMsgDiv = addUserMessage(answer);
    input.value = '';
    
    // 添加"正在思考..."消息
    var thinkingDiv = addThinkingMessage();
    
    try {
        const response = await fetch('/api/conversation/' + currentConvoId + '/stream-answer?answer=' + encodeURIComponent(answer), {
            method: 'GET',
            headers: {
                'Accept': 'text/event-stream'
            }
        });
        
        if (!response.ok) {
            throw new Error('服务器错误: ' + response.status);
        }
        
        thinkingDiv.style.display = 'none';
        
        // 创建 AI 消息容器（用于流式更新）
        var aiMsgDiv = addAIMessage('');
        
        const reader = response.body.getReader();
        const decoder = new TextDecoder();
        let buffer = '';
        let fullContent = '';
        
        while (true) {
            const { done, value } = await reader.read();
            if (done) break;
            
            buffer += decoder.decode(value, { stream: true });
            let lines = buffer.split('\n');
            buffer = lines.pop(); // 保留不完整的行
            
            for (var line of lines) {
                if (line.startsWith('data: ')) {
                    try {
                        var jsonData = JSON.parse(line.substring(6));
                        
                        if (jsonData.event === 'eval') {
                            // 显示评分
                            var evalData = JSON.parse(jsonData.data);
                            updateEvaluation(userMsgDiv, evalData);
                        } else if (jsonData.event === 'question') {
                            // 流式追加内容
                            fullContent += jsonData.data;
                            updateMessageContent(aiMsgDiv, fullContent);
                            scrollToBottom();
                        } else if (jsonData.event === 'done') {
                            // 完成，保存消息
                            saveMessage(fullContent, 'interviewer');
                        }
                    } catch (e) {
                        console.error('解析SSE失败:', e, line);
                    }
                }
            }
        }
        
        scrollToBottom();
        
    } catch (e) {
        console.error('流式请求失败:', e);
        thinkingDiv.style.display = 'none';
        alert('发送失败: ' + e.message);
    } finally {
        sendBtn.disabled = false;
        sendBtn.textContent = '发送 ➤';
        input.disabled = false;
        input.focus();
    }
}

// 更新用户消息的评分显示
function updateEvaluation(userMsgDiv, evalData) {
    var score = evalData.score || 0;
    var feedback = evalData.feedback || '';
    var modelAnswer = evalData.model_answer || '';
    
    var scoreHtml = '';
    if (score !== undefined) {
        var cls = score >= 7 ? 'score-high' : (score >= 4 ? 'score-mid' : 'score-low');
        scoreHtml = '<details class="eval-details ' + cls + '"><summary>得分: ' + score + '/10<span class="eval-expand">查看详情 ▼</span></summary><div class="eval-content"><p><strong>💡 点评:</strong> ' + escapeHtml(feedback) + '</p><p><strong>✨ 参考回答:</strong> ' + escapeHtml(modelAnswer) + '</p></div></details>';
    }
    
    var contentDiv = userMsgDiv.querySelector('.message-content');
    contentDiv.insertAdjacentHTML('afterbegin', scoreHtml);
}
```

## 六、注意事项

1. **LLM 支持**: 确保使用的 LLM API 支持 `stream: true` 参数（OpenAI/MiniMax 都支持）
2. **CORS**: 已配置 `@CrossOrigin(origins = "*")`，SSE 应该可以正常工作
3. **错误处理**: 流式传输中任何环节出错都需要正确关闭连接
4. **性能**: 流式输出会增加服务器连接数，需要注意资源管理
